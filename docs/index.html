THE PROBLEM

Decisions scroll away in terminals you aren't watching.

Agents running in parallel hand decision topics to each other while you look at something else. The important bits scroll past in panes you are not reading. By the time you check, you no longer know who decided what, or why.

One agent asked another to pick a migration strategy. You were reviewing a third pane. Now the choice is made and you never saw the question.

SEE IT IN ACTION

HOW IT WORKS

1

Your agent spawns clause-mcp

Add one entry to your MCP config. Claude Code or any MCP client launches the server. Inside herdr, it tags every note with the workspace and pane it came from.

// ~/.claude.json
"mcpServers": {
  "clause": {
    "command": "clause-mcp"
  }
}
2

Notes land on a floating board

Agents post notes, todos, warnings and decision headlines in real time, grouped by workspace and pane with their names next to the IDs. You add your own directly. The board floats above everything.

3

Decided items drop off

Not an archive. Each pane keeps its 5 most recent decided decisions, older ones go. Clear a whole workspace when you are done with it. Durable tasks belong in your own tracker.

FOUR NOTE TYPES

note

Context and references. The things you need to see while coding but don't want to hold in your head.

todo

Action items and next steps. Mark them done with a click. Completed todos get strikethrough and fade out.

warning

Gotchas, blockers, things that will break if you forget. The notes that prevent the "oh no" moment 20 minutes later.

decision

A short headline for a decision one agent handed to another, or to you. Marked sent until it is made, then decided. Open decisions are counted in the title bar. Every note gets a short ref such as D-12: copy it with a click and ask the agent about it by name. Add a private memo to a decision to keep your own thinking next to it; agents never see memos.

5 MCP TOOLS

Agents use these automatically. Each pane only sees and changes its own notes.

add_note
Add a note, todo, warning, or decision (sent or decided)
list_notes
List this pane's notes
edit_note
Update one of this pane's notes, e.g. mark a decision decided
delete_note
Remove one of this pane's notes
clear_notes
Clear this pane's notes
