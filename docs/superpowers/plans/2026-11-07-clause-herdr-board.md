# Clause herdr Board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Clause from a single-session scratchpad into a multi-workspace, multi-pane observer board where herdr agents post decision headlines (`sent` / `decided`) for the user.

**Architecture:** `clause-mcp` builds an `AgentContext` from `HERDR_WORKSPACE_ID` / `HERDR_PANE_ID` (plus herdr labels) and attaches it to every IPC request. `Clause.app` keeps one flat note list, scopes every agent request to the caller's `(workspaceId, paneId)`, enforces type/status invariants, prunes decided decisions to 5 per pane, and renders workspace > pane groups.

**Tech Stack:** Swift 6, SwiftUI, AppKit, POSIX Unix socket, modelcontextprotocol/swift-sdk, Swift Testing, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-11-07-clause-herdr-board-design.md`

**Revision 2 (2026-11-07):** reordered after a Codex review. UI compile adaptation moved before the store tests can run; type/status invariants added; all three `type` enums updated; entry-point tests for every scoping guarantee; real herdr runner tested; ADR opened at the start; scope key is `(workspaceId, paneId)`.

## Global Constraints

- macOS 14+, Swift 6, Swift Testing (`@Test`, `#expect`), `@Observable`, UI state on `@MainActor`.
- `ClauseConstants.protocolVersion = "2"`, `decidedRetentionPerPane = 5`, `boardFileName = "board.json"`, `herdrTimeoutSeconds: TimeInterval = 2`.
- Outside herdr: `workspaceId = "local"`, `paneId = "pid-<pid>"`, workspace label = basename of cwd.
- Scope key is `(workspaceId, paneId)`. Agent requests are scoped; UI calls are not.
- No new dependencies.
- `Clause.xcodeproj` is tracked and generated by XcodeGen: after adding or deleting a Swift file, run `xcodegen generate`.
- Build/test commands are run by the orchestrator only, sequentially (user approved for this plan on 2026-11-07). Subagents never run them.
- No commits unless the user asks.

Test commands used below:
- `SHARED`: `xcodebuild test -scheme ClauseShared -destination 'platform=macOS' -quiet`
- `APP`: `xcodebuild test -scheme Clause -destination 'platform=macOS' -quiet`
- `MCP`: `xcodebuild -scheme ClauseMCP -configuration Debug build -quiet`

## Review Focus

1. Old-format note JSON (no new fields) must still load. Test `oldNoteJSONDecodes`, Task 1.
2. `clause-mcp` outside herdr must work with the local fallback and make no herdr calls. Tests `contextOutsideHerdr`, `resolveOutsideHerdr`, Task 2.
3. herdr missing, failing or hanging must give `nil` labels within the timeout. Tests `runnerMissingExecutable`, `runnerNonZeroExit`, `runnerTimeout`, Task 2.
4. An agent `clear_notes` must leave other panes and the user's notes intact. Test `clearScopedAtEntry`, Task 5.
5. Converting a decided decision to a plain note must clear `status`/`decidedAt` and drop it from the open count and retention. Test `convertDecisionToNote`, Task 3.

### Task 2: herdr context builder and runner (shared)

**Files:**
- Create: `ClauseShared/Herdr/HerdrContext.swift`
- Test: `ClauseSharedTests/HerdrContextTests.swift`

**Interfaces:**
- Consumes: `AgentContext` (Task 1).
- Produces, on `public enum HerdrContext`:
  - `static func isHerdr(env: [String: String]) -> Bool`: both env vars present and non-empty.
  - `static func baseContext(env:cwd:pid:) -> AgentContext`: herdr IDs with `nil` labels, or `"local"` / `"pid-<pid>"` / basename of cwd.
  - `static func workspaceLabel(fromJSON: Data) -> String?`: `result.workspace.label`, empty → `nil`.
  - `static func agentLabel(fromJSON: Data) -> String?`: `result.agent` → `name`, else `display_agent`, else `agent`, empty skipped.
  - `static func resolve(_ base: AgentContext, env: [String: String], run: ([String]) -> Data?) -> AgentContext`: no `run` calls outside herdr; else `["workspace","get",id]` and `["agent","get",paneId]`.
  - `static func run(executable: String, arguments: [String], timeout: TimeInterval) -> Data?`: `Process`, stdout captured, stderr to `FileHandle.nullDevice`; launch failure, non-zero exit or exceeding `timeout` (process terminated) → `nil`. Must return within `timeout + 0.5` s.
  - `static func runHerdr(_ args: [String]) -> Data?` = `run(executable: "/usr/bin/env", arguments: ["herdr"] + args, timeout: ClauseConstants.herdrTimeoutSeconds)`.
