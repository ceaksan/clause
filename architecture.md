# Clause - Architecture

Minimal, ephemeral observer board for coding agents running in herdr: a floating SwiftUI window paired with an MCP server, communicating over a Unix domain socket. Agents post notes and decision headlines; the user watches every herdr workspace and pane in one panel.

**Key responsibilities per module:**

- `ClauseShared`: Single source of truth for wire types and note invariants. Both processes import this; no duplication.
- `ClauseShared/Herdr/HerdrContext.swift`: Identity. Pure functions plus one process runner; no herdr call outside herdr.
- `ClauseApp/Server/SocketServer.swift`: Accepts POSIX connections, rejects wrong protocol versions and missing contexts, validates `type`/`status`, dispatches to NoteStore on MainActor with the caller's context.
- `ClauseApp/Store/NoteStore.swift`: Central state; every agent mutation is scoped to `(workspaceId, paneId)`; prunes decided decisions; computes the grouped view.
- `ClauseMCP/main.swift`: Registers 5 MCP tools; builds the AgentContext once, resolves labels on `add_note`; forwards each call as an IPCRequest.

## Data Flow

**Flow 1 - Agent to App (MCP tool call):**

```
Agent in a herdr pane (HERDR_WORKSPACE_ID, HERDR_PANE_ID in env)
  --stdin/JSON-RPC-->
    clause-mcp
      --> AgentContext from env (fallback: local / pid-<pid>)
      --> add_note only: herdr workspace get / herdr agent get (2 s timeout each)
      --> IPCRequest {action, params, context, version: "2"}
        --Unix socket (~/.clause/clause.sock)-->
          SocketServer.handleRequest (ClauseApp, @MainActor)
            --> version check, context check, param validation
              --> NoteStore.addNote / editNote / deleteNote / clearNotes / listNotes (caller-scoped)
                --> normalize + prune decided
            <-- IPCResponse
      --> stdout / JSON-RPC result
```

**Flow 2 - User to App (direct UI interaction):**

```
User types in InputBar / toggles a todo / clears a workspace
  --> NoteStore (unscoped)
    --> @Observable triggers SwiftUI diffing
      --> debounce (500 ms) or periodic flush (10 s)
        --> JSON snapshot written to ~/.clause/board.json
```

## MCP Tools

```
add_note(text, type?, status?)                       # Post a note or a decision headline (decision defaults to sent)
list_notes(type?)                                    # This pane's notes only
edit_note(id, text?, type?, completed?, status?)     # This pane's notes only; set status decided when answered
delete_note(id)                                      # This pane's notes only
clear_notes()                                        # This pane's notes only
```

| Tool | Key Parameters | Returns |
|------|---------------|---------|
| add_note | text (max 4096), type: note/todo/warning/decision, status: sent/decided (decisions only) | id, ts |
| list_notes | type? | notes JSON (id, ts, type, status, text, completed) |
| edit_note | id, text?, type?, completed?, status? | ok, or notFound for other panes' notes |
| delete_note | id | ok, or notFound |
| clear_notes | none | cleared count |

Errors: `invalidParams` for unknown type/status, status on a non-decision, missing context, unknown action; `versionMismatch` for any version other than "2".

## Data Model

**Note** (in-memory + persisted in board.json):

| Field | Type | Notes |
|-------|------|-------|
| id | UUID | Primary key |
| timestamp | Date | Set at creation |
| source | enum: claude, user | Origin |
| type | enum: note, todo, warning, decision | Badge and filtering |
| text | String | Max 4096 chars; truncated on input |
| completed | Bool | Todos |
| workspaceId, paneId | String? | Scope key; nil for user notes |
| workspaceLabel, agentLabel | String? | Display only; nil when herdr lookup failed |
| status | enum: sent, decided? | Decisions only |
| decidedAt | Date? | Set exactly when status is decided |

Invariants (enforced by `Note.normalize()` after every write): a decision always has a status (default sent); non-decisions have no status and no decidedAt; decidedAt is non-nil exactly when status is decided.

**AgentContext**: workspaceId, paneId, workspaceLabel?, agentLabel?, pid. Sent with every IPC request.

Retention: each `(workspaceId, paneId)` keeps its 5 most recently decided decisions.

## Configuration & Environment

| Variable | Purpose | Secret |
|----------|---------|--------|
| HERDR_WORKSPACE_ID | Workspace scope, set by herdr in every pane | No |
| HERDR_PANE_ID | Pane scope, set by herdr in every pane | No |

Outside herdr, clause-mcp uses workspace `local`, pane `pid-<pid>` and the basename of its working directory as the workspace label.

**File system paths:**

| Path | Purpose |
|------|---------|
| ~/.clause/ | App data directory, created with 0o700 permissions |
| ~/.clause/clause.sock | Unix domain socket; created by ClauseApp on launch |
| ~/.clause/board.json | Debounced board snapshot |
| ~/.clause/sessions/ | Legacy per-session files from protocol 1; no longer read or written |

No external services, no API keys, no network access.

## Security

- Unix socket directory (~/.clause/) is created with 0o700; socket reachable only by the current user
- No inbound network connections; ClauseApp is entirely local
- Note text truncated at 4096 chars on ingestion
- Protocol version checked on every request; mismatch returns ErrorCode -5
- Pane scoping keeps one agent's notes out of another agent's tool output; it is not authentication, any local process running as the user can claim any context
- No sandboxing entitlements required

## Constraints & Trade-offs

| Decision | Reason | Trade-off |
|----------|--------|-----------|
| POSIX sockets on both sides | NWListener does not support AF_UNIX server binding | Manual fd and buffer handling in SocketServer.swift and main.swift |
| In-memory state with debounced JSON snapshot | Simple, fast, the board is ephemeral by design | Up to 10 s of loss on crash |
| One board, scoped per `(workspaceId, paneId)` | Many agents in many workspaces at once, no setup call | Pane ID uniqueness across herdr restarts is unverified |
| Labels resolved in clause-mcp on add_note | Renames appear on the next note; the app never shells out | add_note waits up to about 4 s if herdr hangs |
| Agents only see their own pane | Clause is the user's board, not an agent channel | Agents cannot coordinate through Clause (intended) |
| No encryption on Unix socket | Local-only, same-user IPC | Not suitable for multi-user or remote access |
| LSUIElement app (no dock icon) | Floating companion | Requires explicit window activation |

## Known Tech Debt

**High priority:**
- [ ] FloatingPanel.swift exists but is not used; configureWindow() patches a standard NSWindow
- [ ] No accessibility permission handling (required for global hotkey in Milestone 2)

**Medium priority:**
- [ ] Hotkey support not implemented
- [ ] Agents only post if their instruction files say so (CLAUDE.md / AGENTS.md rule, outside this repo)

**Low priority:**
- [ ] Legacy ~/.clause/sessions/ directory is left on disk
- [ ] No graceful socket cleanup on abnormal app termination; stale .sock file can block next launch
- [ ] main.swift:116 request-timeout Task result is unused (compiler warning)
